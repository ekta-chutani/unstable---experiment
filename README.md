# unstable---experiment
UNSTABLE // EXPERIMENT 07 — An interactive web toy built with HTML, CSS and JavaScript.

## Concept

UNSTABLE // EXPERIMENT 07 is a futuristic experimental interface designed around user curiosity, uncertainty, and interaction. The experience gradually responds to the user's actions through changing system diagnostics and interactive challenges.

## Features

- Interactive "DO NOT PRESS" primary interaction
- Dynamic system diagnostics
- Instability challenge
- Reaction-time test
- Responsive futuristic interface
- Animated visual effects

## Technologies

- HTML5
- CSS3
- JavaScript
